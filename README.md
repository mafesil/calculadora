# Calculadora de campo

App web para uso em campo, instalável no celular e funcional sem internet.

- **Vazão da bomba:** vazão na frequência aplicada, a partir da capacidade nominal.
- **Rotação × Hz:** rotação do motor pelo Hz e frequência necessária para uma rotação.

## Publicar no GitHub Pages
1. Crie um repositório público (ex.: `calculadora-campo`).
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Em *Settings → Pages*, escolha *Deploy from a branch*, branch `main`, pasta `/ (root)`.
4. O link fica: `https://<seu-usuario>.github.io/calculadora-campo/`

## Instalar no celular
- **Android (Chrome):** abra o link → menu ⋮ → *Instalar app*.
- **iPhone (Safari):** abra o link → Compartilhar → *Adicionar à Tela de Início*.

## Atualizar
Ao alterar algum arquivo, mude `VERSAO` em `sw.js` (ex.: `calc-campo-v2`) para os celulares baixarem a nova versão.
